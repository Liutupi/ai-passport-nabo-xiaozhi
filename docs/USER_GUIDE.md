# 使用指南

## 配网与激活

首次启动按照工牌屏幕提示，用手机完成 2.4 GHz Wi-Fi 配网。若进入热点配网，连接屏幕显示的 `Xiaozhi-xxxx`，访问 `http://192.168.4.1`。随后在 <https://xiaozhi.me> 添加设备并输入屏幕上的激活码。热点名、蓝牙名由每块设备生成，不能照抄示例尾号。

已有本定制固件且已激活的设备，通过应用升级保留配置。OK 开始/结束小智对话；本版未启用本地唤醒词。

## 语音打开

在小智主页按 OK 开始对话，说：

- “打开摇骰子”或“打开骰子”。
- “打开木鱼”或“打开功德木鱼”。
- “打开网络电台”。
- “打开跳一跳”。
- “打开节奏回声”或“打开节奏游戏”。
- “打开电脑快捷键”或“打开电脑控制”。
- “打开设置”或“打开工具”。

支持“请帮我打开木鱼”“启动网络电台”等明确指令。语音识别仍需要服务器和网络；设备收到识别结果后直接打开程序。“不要打开木鱼”“如何打开电台”等否定/询问句不会被本地规则直接执行。一次请只打开一个程序。

进入本地程序后小智暂停。长按上键回到小智，再按 OK 继续对话并打开下一项。

## 跳一跳

按住 OK，NABO 屈膝蓄力；松开后摆臂蹬地起跳。落地会屈膝缓冲并站稳。跳空时掉在平台旁边，撑地跌坐后结束，人物保留在画面里。

落地和镜头移动期间就可以开始下一次蓄力，无需等镜头停稳。提前松开也会保留实际按住时间。正中连击依次加 2、4、6 分，最高分保存到设备。

平台包括医院、书房、播客、木鱼、咖啡和靶心。下键可切换经典棋子，长按下键重新开始。

越往后越难：前几跳和以前一样；约第 8 跳起平台间距逐渐拉大，并穿插缩小到 72% 的“迷你”平台；约第 20 跳起出现**一人位**小平台——外带咖啡、拿铁咖啡、冰美式、迷你电脑、小音箱、黑胶唱片，杯口/台面刚好站下一个 NABO，落点容差从 ±16 px 收紧到 ±9 px，站上去额外加 1 分。左上角“下一站”会提前告诉你下一块是什么。

## 节奏回声

工具菜单第三项。选关页 12 个色块对应三种玩法和 I–IV 关，色块里是速度（BPM），右上角是该关最好评级。上/下选关，OK 开始，双击上键回工具。

每关先有一小节预备拍，然后四句：**LISTEN** 小节播放示范，黑条上的切口就是拍点；**YOUR TURN** 小节轮到你，在同样的位置按回去。回声关 OK 和下键都算；对唱关蓝色切口是高音，用下键，其余用 OK。偏差 60 ms 内为 PERFECT、125 ms 内为 GOOD，漏拍画叉，示范后乱按会扣分。70% 以上过关，结算页 OK 进入下一关，下键重来。

判定以按下瞬间为准。若总觉得偏早或偏晚，可在开发串口发送 `>rhythm.latency=42`（毫秒，默认 42）微调；`>rhythm.best.reset` 清除成绩。

## 电台与电脑快捷键

网络电台包含 47 台目录，按页面提示选择分类/收藏、台站和播放器操作。双击上键逐层返回。电台 URL 由外部服务维护，某台不可用时可换台。

电脑快捷键需要先在电脑蓝牙设置中配对工牌屏幕显示的 `NABO-Xiaozhi-xxxx`。工牌同时是蓝牙键盘、媒体键和滚轮鼠标，只在程序打开期间运行。菜单只保留高频操作：

| 菜单 | 内容 |
|---|---|
| 滑动遥控 | 上/下键滑动（按住连续滑），双击上键上一页，短按 OK 向右翻页，长按 OK 退出遥控。适合微信读书、网页和文档 |
| 鼠标与翻页 | 向上滑、向下滑、上一页、向右翻页、返回上页、鼠标单击、鼠标右键 |
| 常用操作 | 确认/发送、取消/退出、复制、粘贴、撤销、切换应用、显示桌面、区域截图、锁定电脑 |
| 影音播放 | 播放/暂停、快退、快进、音量增减、静音、上一曲、下一曲 |
| Typeless 与 AI | 听写/结束、语音翻译、语音提问 |
| 连接与设置 | 电脑系统（Windows / Mac）、滚动方向、重新连接、按键说明 |

在电脑上让微信读书阅读窗口获得焦点，进入工牌“滑动遥控”：上/下键滚动，双击上键发送方向键左（上一页），短按 OK 发送方向键右（下一页），两者都不带修饰键；长按 OK 返回电脑快捷键菜单。“鼠标与翻页”列表也可单独执行这两个翻页操作。为区分单双击，上键短按在单击判定后滑动；按住上键 450 ms 后开始连续滑动，下键按下即滑。

Mac 默认开启“自然滚动”，工牌在 Mac 模式下已自动反向；如果你的电脑滑动方向相反，在“连接与设置 → 滚动方向”切换为“反向”，设置会保存。“返回上页”在 Windows 为 Alt+←，Mac 为 Cmd+[；快退/快进是方向键，适用于 B 站、YouTube 等网页播放器。向右翻页在 Windows/Mac 均为标准方向键右，不受滚动反向设置影响。

**从 v1.2 及更早版本升级后，请在电脑蓝牙设置中删除 `NABO-Xiaozhi-xxxx` 再重新配对一次**，否则电脑沿用旧的纯键盘描述，键盘可用但滚轮和鼠标点击无效（屏幕会提示“滑动需在电脑上删除本设备后重新配对”）。

Windows 的语音输入、翻译、询问映射为 RAlt、RAlt+RShift、RAlt+Space；对应电脑软件也需要设置这些快捷键。Mac 对应 F13、F14、F15。v1.2 用 USB 串口 `keys.map` 设置过的 Typeless、复制、粘贴等自定义按键会自动迁移；已删除的操作的自定义不再保留。

## 声音与设置

骰子和木鱼沿用旧项目的 16 kHz 双声道 I2S 播放方式。跳一跳蓄力声采用 0.65 幅度和淡入淡出，切换声音有短过渡。界面 100% 音量仍给小扬声器保留输出余量；请根据环境调整。

设置包含音量、扬声器、亮度、休眠、麦克风增益、添加网络、Wi-Fi 开关、状态、电池、关闭屏幕和关机。USB 接入时保持待机屏幕亮起，手动关闭屏幕仍可使用。

## 排查

无法语音打开时，先确认能正常对话、屏幕识别文字与命令一致，并且当前在小智主页。固件不是完全离线语音识别。

对话重连时先核对 Wi-Fi 与服务器。需要报告固件问题时，请提供 Release 版本和去除私人内容的错误堆栈；不要上传 NVS、整片备份、账号令牌或完整私人对话。
